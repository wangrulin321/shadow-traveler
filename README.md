# 影灯旅人 · 光影滑行扩展版

一个可本地运行的 8×8 光影滑行解谜游戏。

## 运行

在 PowerShell 中进入本目录后执行：

```powershell
./serve.ps1
```

然后打开 <http://localhost:4173>。

也可以直接双击 `index.html`，但使用本地服务更稳定。

## 第一版规则

- 只有一只亮色惧暗小人。
- 小人选择方向后会持续滑动，遇到实体墙或影墙才会停下。
- 没有墙阻挡时会滑出 8×8 棋盘并失败。
- 灯沿四个方向照亮格子；墙会挡住移动，也会挡住光线。
- 亮色惧暗小人可以穿过暗区，但不能在暗区停下；停靠在暗区会失败。
- 每关墙体库存不同，移动次数不限制。
- 共 12 个关卡，包含交错光廊、多灯回环、影墙折线等复杂布局，失败后可以重新开始。
